DISPUTE DESK 2, HOME SCREEN APP
Version b78a6ace36

WHAT THIS IS
Dispute Desk 2 as an app on your iPhone Home Screen. It opens full screen and works with no signal. It has a Home screen, five tabs (Home, Case, Evidence, Letters, Send), a Learn page, and a light or dark look. It can keep your case and your evidence photos on the phone, but only if you turn on "Save this case on this device" on the Home screen. It starts off.

WHAT IT CAN'T DO
- It doesn't mail letters, call anyone, or file the FTC form for you. You do those.
- "Read it for me" (the Claude intake box) only works in the version inside Claude. It isn't in this app.
- Nothing leaves your phone. There is no account and no server.
- It uses no company logos. The round badges next to creditor names are made up from the first letters of the name.

PUT IT ON YOUR HOME SCREEN, USING ONLY YOUR iPHONE
Apple only lets a website go on the Home Screen from an https address, so the 10 files in this folder have to be on a website once. GitHub Pages does that for free. These steps match GitHub's and Apple's own help pages. They have not been tried on a real iPhone, so if a screen looks different, tell me what it says.

1. Unzip. In the Files app, tap dispute-desk-2-app.zip. A folder opens with 10 files in it and no folders.
2. Open github.com in Safari and sign in. Make a free account if you don't have one.
3. Make a repository. Tap the menu at the top right, then New repository. Name it dispute-desk-2. Choose Public (a free account needs Public for Pages). Tap Create repository.
4. Upload the files. Tap "uploading an existing file", or tap Add file and then Upload files. Tap "choose your files", then Choose Files. Open the unzipped folder, tap Select, tap every file, then tap Open. Wait until all 10 are listed. Tap Commit changes.
5. Turn on Pages. Tap Settings (it may be under the three-dots menu), then Pages. Under Build and deployment set Source to "Deploy from a branch". Set the branch to main and the folder to /(root). Tap Save.
6. Wait up to 10 minutes, then open the Pages screen again. It shows your address, like https://yourname.github.io/dispute-desk-2/
7. Open that address in Safari. Tap Share (the square with an arrow, or the three-dots page menu and then Share). Tap Add to Home Screen. If it isn't in the list, scroll to the bottom, tap Edit Actions, and tap the + next to Add to Home Screen. Turn on "Open as Web App". Tap Add. You can shorten the name under the icon before you tap Add.
8. Open Dispute Desk 2 from its new icon from now on, not from Safari.

If Settings or Pages doesn't show: tap aA in Safari's address bar, then Request Desktop Website, and look again.
If the upload screen won't take a file: the picker can't choose a whole folder. Open the folder first, then pick the files inside it.

ABOUT THE WEBSITE
- It is public. Anyone who has the address can open the empty app. It holds nobody's case. A case you type never goes to the website. It stays on your phone, and only if you turn saving on.
- A free GitHub account needs the repository to be Public for Pages.
- To take it down, delete the repository: Settings, scroll to the bottom, Delete this repository.
- Any other host that serves plain files over https also works with these same files.
- It does not touch an older Dispute Desk on the same GitHub account. This app keeps its own saved data under its own names.

GOOD TO KNOW
- Open it from the Home Screen icon, not from Safari. Safari can erase a website's saved data after about a week without a visit. A Home Screen app is treated differently.
- Saving is a choice and starts off. With it off, nothing about the case is written to the phone, and closing the app clears the case and the evidence photos. Leaving the app for a while can also reload it, so turn on "Save this case on this device" on the Home screen if you will step away.
- Evidence photos and PDFs live on the phone only. They are never uploaded and never go into a case code. Each file can be up to 12 MB. Cover Social Security and full account numbers before you take a photo.
- A drawn or typed signature is never saved and is never in a case code. You sign again after closing the app.
- "Start a new person's case" (on the Home screen) clears the last person's details, addresses, letters, signature, evidence files and any saved copy, and turns saving back off.
- Cases stay in the app only. Use "Copy case code" under "Move this case" on the Send screen to back one up or move it to another device. The code has no signature and no files in it.
- To save a letter as a PDF, tap Save as PDF. The iPhone share sheet opens: Save to Files, Print, Mail, AirDrop.
- To update the app, upload the new files to the same repository with the same names (Add file, Upload files). The app shows "A new version is ready" the next time it opens online. Tap Update.
- This is the same page that runs inside Claude, plus the offline cache. The Claude version also keeps a private backup in your Claude account. This one doesn't.
